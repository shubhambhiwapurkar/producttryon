# RingFIR demo pack

46 gold earring photos, one per style, from the RingFIR dataset:
https://github.com/skarifahmed/RingFIR (MIT licence, see LICENSE).

Islam S.M., Joardar S., Sekh A.A. (2021) RingFIR: A Large Volume Earring Dataset
for Fashion Image Retrieval. CVIP 2020, CCIS vol 1377, Springer.

The photos come from jewellery catalogues. Use them for private demos only,
not for public marketing.

Load them with:

    python -m scripts.seed_ringfir demo/ringfir --store demo --create "Maison Aurelia"
